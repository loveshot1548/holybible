# Church Sketch Icon Set (Complete)

- 48 hand-drawn outline icons
- Individual SVG files in `svg/`
- React component `SketchIcon.jsx`
- Color, size, strokeWidth customizable

## Usage
```jsx
import SketchIcon from './SketchIcon';
<SketchIcon name="flame" size={36} color="#4383DE" strokeWidth={2.6} />
```
